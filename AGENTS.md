# AI-assisted contributions to ReVolta

Read [CONTRIBUTING.md](CONTRIBUTING.md) before preparing a change. ReVolta
maintains its own support scope; inherited vLLM features are not support promises.

- A human contributor must understand and review every changed line, run the
  relevant checks, and take responsibility for the submission.
- Disclose AI assistance and report actual test commands and results. Identify
  hardware-dependent checks that were not run.
- Preserve upstream attribution, license notices and source references.
- Keep changes focused. Do not expand supported hardware or model claims
  without evidence and maintainer agreement.
- Use `uv` and a project virtual environment for Python work. Run the existing
  pre-commit hooks on changed files before submitting.
