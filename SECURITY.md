# ReVolta security policy

This page explains which releases receive security fixes and how to report a vulnerability privately.

## Supported versions

| Version | Security fixes |
| --- | --- |
| 0.2.x (latest: 0.2.0) | Yes |
| 0.2.0 release candidates (`0.2.0rcN`) | No; upgrade to 0.2.0 |
| 0.1.x and earlier | No; upgrade to 0.2.0 |

Fixes land on `main` and ship in the next 0.2.x release. There is no guaranteed response time and no separate long-term maintenance for older releases.

## Report a vulnerability

Use this repository's GitHub **Security → Advisories → Report a vulnerability** form (private vulnerability reporting). Do not put exploit details, credentials or private data in a public issue.

Include the affected version or commit, the configuration, the impact, reproduction steps and any suggested mitigation. The maintainers coordinate investigation, fixes and disclosure with the reporter.
